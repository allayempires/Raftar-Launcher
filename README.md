# ⚡ Raftar Launcher
---

## 🎮 About

**Raftar Launcher** is an Android launcher for Minecraft: Java Edition,
focused on providing a modern UI, easy instance management and convenient
Minecraft content management.

The project is designed to provide a clean and fast launcher experience
while keeping useful Minecraft Java Edition features accessible on Android.

---

## ✨ Features

- 🎮 Minecraft: Java Edition
- ⚡ Fast and lightweight launcher
- 🎨 Custom Raftar Launcher interface
- 👤 Local / Offline accounts
- 👕 Skin management
- 📦 Minecraft instance management
- 🧩 Mods
- 📚 Modpacks
- 🎨 Resource Packs
- 🌌 Shaders
- 🌍 Worlds
- 🎛️ Custom controls editor
- ⚙️ Launcher settings
- 📱 Portrait and landscape support
- 🔄 Minecraft version management
- 💾 Instance-specific game directories
- 📥 Built-in content downloader
- 🌙 Modern gaming-focused UI

---

## 📥 Downloads

Raftar Launcher provides a centralized Downloads hub for Minecraft
content.

### Supported content

| Type | Installation Directory |
|------|------------------------|
| Mods | `mods/` |
| Modpacks | Modpack installation system |
| Resource Packs | `resourcepacks/` |
| Shaders | `shaderpacks/` |
| Worlds | `saves/` |

Content is installed according to its actual type instead of using a
single generic directory.

## 🖥️ Interface

Raftar Launcher is designed to provide a responsive experience across:

- 📱 Portrait
- 📱 Landscape
- 📟 Larger Android displays

The launcher UI is designed around the Raftar Launcher branding and
gaming-focused visual style.
